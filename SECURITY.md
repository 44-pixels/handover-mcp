# Security

Do not open a public issue for a suspected vulnerability involving Handover,
its authentication flow, tenant isolation, or agent credentials.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected endpoint or MCP tool;
- the identity type used;
- reproduction steps;
- the expected and observed access boundary;
- whether any real workspace data may have been exposed.

Never include active tokens, OAuth codes, cookies, private handover contents,
or customer data in a report.

Public product security documentation is available at
https://handover.sh/security.
